# Day 01
## Bentley Torcal - Coming Soon Page 🏎️

A premium, modern "Coming Soon" landing page featuring a fully functional dynamic countdown timer. 

### ✨ Features
- **Dynamic Countdown Timer:** Built with vanilla JavaScript to calculate and display days, hours, minutes, and seconds in real-time.
- **Modern Layout:** Utilizes CSS Flexbox for perfect horizontal and vertical alignment of navigation menus and hero sections.
- **Premium UI/UX:** Clean, transparent button designs and responsive background image styling (`background-size: cover`) for a high-end automotive brand feel.

### 🛠️ Technologies Used
- **HTML5 & CSS3:** Semantic structure and custom styling using Flexbox.
- **JavaScript:** DOM manipulation (`getElementById`, `innerHTML`) and timing events (`setInterval`).

### 🧠 What I Learned
- **Emmet:** Mastered using Emmet abbreviations in VS Code to write complex HTML structures and CSS properties significantly faster.
- **State Management:** Learned how to convert total time into seconds and continuously update the UI using JavaScript intervals.

# Day 02
## Full-Screen Mobile Navigation & Premium Animations 📱✨

A premium, full-screen mobile navigation menu with smooth, high-end CSS transitions and interactive JavaScript toggles.

### ✨ Features
- **Full-Screen Overlay Menu:** A professional, screen-covering navigation menu that mimics the official Bentley website design.
- **Premium Animations:** Implemented a sophisticated two-step animation sequence where the white background slides down first, followed by the menu links smoothly sliding in from the left.
- **Interactive UI Toggles:** Fully functional Hamburger (☰) open button and ('X') close button powered by real-time JavaScript event listeners.

### 🛠️ Technologies Used
- **Advanced CSS3:** `position: fixed` for overlays, `z-index` for layering, and `transition` / `transition-delay` for staggered animations.
- **Vanilla JavaScript:** `addEventListener` for user interactions, and dynamic UI updates using `classList.toggle()` and `classList.remove()`.

### 🧠 What I Learned
- **DOM Manipulation & Events:** How to capture elements and attach click events to add or remove CSS classes, effectively creating functional "switches" for the UI.
- **CSS Animation Logic:** Mastered the technique of hiding elements off-screen (`top: -100%`, `left: -100%`) and smoothly transitioning them into view to create a high-end, non-blocking user experience.
- **Semantic HTML Rules:** Discovered that a web page should strictly have only one `<main>` tag for core content, and learned to correctly restructure secondary components using `<div>` and `<nav>`.
- **Advanced Flexbox:** Applied `flex-direction: column` to correctly stack vertical menu links, and learned how to use `justify-content: space-between` to push elements to opposite ends of a container.
